# API

Interactive documentation is generated by FastAPI at `/docs`. Every analytical response includes methodology version, limitations, and `evidence_class` when it is about a dataset.

Envelope: `{ "data": ... }` or `{ "error": { "code", "message", "details" } }`.

If `QM_API_KEY` is set, send `X-API-Key`.

## Health and methodology

`GET /health`

```json
{"status":"ok","database":"up","ai":{"configured":false,"required":false}}
```

`GET /api/methodology` returns the canonical method text.

## Datasets

`POST /api/datasets/import` multipart fields: `name`, optional `description`, `is_synthetic`, file `responses`, optional files `topics`, `prerequisites`, `allocations`.

`POST /api/datasets/demo?students_per_school_grade=24` loads the synthetic generator, including textbook text. The response is labeled synthetic.

`GET /api/datasets`

`GET /api/datasets/{id}`

`GET /api/datasets/{id}/summary`

`GET /api/datasets/{id}/imports`

`GET /api/datasets/{id}/issues`

`DELETE /api/datasets/{id}`

`GET /api/assessments?dataset_id=`

## Diagnostics

`GET /api/analytics/overview?dataset_id=&min_students=30`

`GET /api/analytics/topics?dataset_id=&min_students=30`

`GET /api/analytics/topics/{topic_id}?dataset_id=`

Topic objects include accuracy, student-level t interval, supplementary Wilson interval, status, flags, difficulty index, and a plain-language explanation. Status is `insufficient_data`, `not_assessed`, `weak`, `strong`, or `inconclusive`.

## Knowledge graph

`GET /api/knowledge-graph?dataset_id=`

`GET /api/knowledge-graph/risks?dataset_id=`

`GET /api/knowledge-graph/export?dataset_id=` returns `{nodes, edges}` for a later graph UI. Edge field `established` is true only for human-asserted verified edges.

`POST /api/knowledge-graph/edges?dataset_id=` body:

```json
{"prerequisite_topic_id":"T06","dependent_topic_id":"T12","relation_status":"verified","notes":"Curriculum map 2025"}
```

`POST /api/knowledge-graph/infer?dataset_id=` returns candidates. It does not save them.

## Textbooks

`POST /api/textbooks/ingest` multipart: `dataset_id`, `material_id`, `title`, `upload` (`.txt` or `.pdf`).

`GET /api/textbooks?dataset_id=`

`GET /api/textbooks/{material_id}?dataset_id=`

`POST /api/textbook-comparison?dataset_id=`

Structural coverage and outcome means are separate. Outcome notes say the mean is not a textbook effect.

## Hours and optimization

`GET /api/curriculum/allocations?dataset_id=`

`POST /api/optimization/scenarios`

```json
{
  "dataset_id": "DATASET_ID",
  "total_hours": 100,
  "beta": 0.15,
  "transfer_tau": 0.25,
  "target_accuracy": 0.75,
  "max_change_hours": 4,
  "proposed_hours": {"T06": 12, "T12": 10}
}
```

`learning_response_estimated_from_data` is false. Infeasible bounds return HTTP 422 and no invented plan. `GET /api/optimization/scenarios?dataset_id=` lists stored runs. `GET /api/optimization/scenarios/{artifact_id}` returns one.

`chart.series` is ready for a later bar chart. `comparison[].objective_sensitive` is true when linear and nonlinear scenarios move a topic in opposite directions.

## Causal contrast

`POST /api/causal-analysis`

```json
{"dataset_id":"DATASET_ID","material_a":"TB_ALPHA","material_b":"TB_BETA","n_bootstrap":200}
```

`causal_conclusion` is always `not_claimed`. `claim_level` is `not_comparable`, `association_only`, or `estimated_effect_under_untestable_assumptions`.

## Recommendations, reports, AI

`POST /api/recommendations/generate?dataset_id=`

`GET /api/recommendations?dataset_id=`

Each recommendation has a confirmed observation, possible explanations, evidence copied from the engines, `intervention_confidence: not_estimated`, and `not_a_proven_intervention: true`.

`POST /api/reports/generate` body `{"dataset_id":"..."}`.

`GET /api/reports/{id}`

`GET /api/reports/{id}/download?format=pdf|csv|json`

CSV is a zip of aggregate tables. PDF and JSON do not list student ids.

`GET /api/ai/status`

`POST /api/ai/explain`

```json
{"dataset_id":"DATASET_ID","task":"diagnostics","question":"Where should a methodologist look first?"}
```

Without `GEMINI_API_KEY`, `used_fallback` is true and the text is formatted from engine facts. If a model returns numbers that are not in those facts, the narrative is discarded.
