# Synthetic demonstration data

`sample_data/demo/` is generated by `app/demo/generator.py` with seed 7. It is not real student evidence. Every API object loaded from it has `evidence_class: synthetic`.

## Design

- 4 schools, grades 7–9, 24 students per school per grade (288 students).
- 17 mathematics topics and a verified prerequisite map.
- Two assessment dates: 2024-10-15 and 2025-03-20.
- 14,594 accepted item rows in the checked-in file.
- Two synthetic textbooks, Alpha and Beta.
- A 100-hour allocation across 12 topics.

## Data-generating process

For each student:

```
ability ~ Normal(school_mean, 0.45)
P(material = TB_ALPHA) = sigmoid(0.8 * ability)
```

Topics are generated in prerequisite order:

```
penalty = 0.55 * sum(max(0, -latent_prereq))
latent = ability + school_topic_shift - difficulty - penalty + material_bonus
material_bonus = 0.12 if TB_ALPHA else 0
item correct ~ Bernoulli(sigmoid(latent + period_shift + N(0, 0.25)))
```

School shifts, which are generator settings rather than estimated effects:

- North Secondary, factoring (`T06`): -1.15
- South Secondary, geometry topics `T09`, `T16`, `T17`: -0.85

Probability (`T15`) is intentionally almost unassessed: one question, and only a West Secondary student whose index is divisible by 17. On seed 7 that is 1 student. The diagnostics rule therefore returns `insufficient_data`.

Topic difficulties are also generator settings, chosen so the file contains both secure topics and weak topics. They are not IRT parameters.

## What the engine finds on seed 7

These figures come from `scripts/summarize_demo.py`. They describe the synthetic file only.

- Integers (`T01`) mean student credit 0.8789, n=96, status strong.
- Descriptive statistics (`T11`) 0.8164, n=96, status strong.
- Factoring (`T06`) 0.4238, n=192, status weak.
- Quadratic equations (`T12`) 0.4427, n=96, status weak, with a verified upstream-gap hypothesis because linear equations and factoring are also weak.
- Probability (`T15`) n=1, insufficient data.
- Geometry topics carry `inconsistent_across_schools` because South Secondary was generated with a negative geometry shift.
- The hypothetical diminishing-returns scenario moves factoring from 8 to 18 hours and quadratic equations from 14 to about 8 hours. Linear and nonlinear objectives disagree in direction on some topics, including quadratic equations. That sensitivity is reported. It is not a predicted score gain.

The small Alpha material bonus is confounded with ability because higher-ability students are more likely to be assigned Alpha. The causal module must not turn that into a causal conclusion.
